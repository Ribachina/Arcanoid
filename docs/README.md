# 🧱 Arcanoid

> 🚧 **Проект находится в разработке**

Учебная реализация классической игры **Arkanoid / Breakout** на **C++** с использованием библиотеки **SFML**.

Основная цель проекта — практика архитектуры игровых приложений, работы с игровыми состояниями, коллизиями, движением объектов и библиотекой SFML.

На данный момент реализована базовая игровая механика. Проект постепенно дополняется новыми возможностями и может содержать незавершённые функции.

## 🎮 Текущее состояние

Уже реализовано:

- главное меню;
- игровой цикл;
- управление платформой;
- движение мяча;
- запуск мяча с платформы;
- столкновения мяча:
  - с платформой;
  - с границами игрового поля;
  - с блоками;
- уничтожение блоков;
- возврат мяча на платформу после падения;
- состояние победы после уничтожения всех блоков;
- разделение логики на игровые состояния;
- отдельные классы для основных игровых объектов.

## 🕹 Управление

| Клавиша | Действие |
|---|---|
| `←` | движение платформы влево |
| `→` | движение платформы вправо |
| `Space` | запустить мяч |

Управление и другие игровые механики могут изменяться по мере разработки проекта.

## 🎯 Цель игры

Игрок управляет платформой в нижней части экрана.

Необходимо отбивать мяч платформой и разрушить все блоки в верхней части игрового поля.

Когда все блоки уничтожены, игра переходит в состояние победы.

## 🧩 Архитектура

Проект разделён на игровые состояния.

На данный момент используются:

```text
MainMenu
Playing
Victory
```

Класс `Game` отвечает за:

1. создание игрового окна;
2. обработку событий;
3. обновление текущего состояния;
4. отрисовку кадра;
5. переключение между состояниями.

Каждое состояние наследуется от общего интерфейса игрового состояния и самостоятельно обрабатывает свою игровую логику.

Пример переходов:

```text
MainMenu
   │
   ▼
Playing
   │
   │ все блоки уничтожены
   ▼
Victory
```

Такой подход позволяет добавлять новые состояния без переноса всей логики в один большой игровой класс.

## ⚙️ Игровое поле

Текущий размер окна:

```text
800 × 600
```

Основные игровые объекты создаются внутри этого пространства.

В текущей реализации в начале игры создаётся ряд из **10 блоков**.

## ⚽ Игровая механика

### Платформа

Платформа располагается в нижней части экрана и перемещается горизонтально.

Начальный размер платформы:

```text
100 × 10
```

Скорость движения:

```text
500 px/s
```

### Мяч

Мяч изначально находится рядом с платформой и начинает движение после нажатия `Space`.

Текущий радиус мяча:

```text
10 px
```

Начальная скорость движения:

```text
500 px/s
```

После падения за нижнюю границу игрового поля мяч сбрасывается и снова прикрепляется к платформе.

### Блоки

Сейчас игровое состояние создаёт:

```text
10 блоков
```

Размер каждого блока:

```text
60 × 20
```

При столкновении мяча с блоком:

1. мяч отражается;
2. блок удаляется с игрового поля.

Когда блоков не остаётся, игра переходит в состояние `Victory`.

## 💥 Коллизии

Для определения столкновений используется проверка пересечения прямоугольных границ объектов.

Отдельный модуль:

```text
Collision.cpp
Collision.hpp
```

используется для проверки пересечения `sf::FloatRect`.

Это позволяет не привязывать систему коллизий напрямую к конкретному типу игрового объекта.

## 🔄 Игровой цикл

Основной цикл организован по классической схеме:

```cpp
Input();
Update(deltaTime);
Draw();
```

Для обновления объектов используется `deltaTime`, поэтому скорость движения не должна напрямую зависеть от количества кадров в секунду.
